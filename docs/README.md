## Исторические документы

Файлы в `history/` перенесены из корня исходного архива без изменения содержания. Это планы, трекеры и журналы разработки. Их статусы и утверждения относятся к моменту создания и **не подтверждают**, что текущая версия собирается, проходит тесты или готова к реальной торговле.

**Основной сводный документ:** [history/MASTER-PLAN.md](history/MASTER-PLAN.md) — единый мастер-план, объединяющий предыдущие, текущие и будущие планы в один порядок работ. Исходные файлы ниже сохранены как детали/аудит; при противоречии приоритет имеет мастер-план.

| Файл | Содержание |
|---|---|
| [history/MASTER-PLAN.md](history/MASTER-PLAN.md) | Единый мастер-план: baseline, блокеры, Phases 0–11, критерии готовности |
| [history/plan.md](history/plan.md) | Основной исторический план и прогресс правок |
| [history/changes.md](history/changes.md) | Журнал изменений |
| [history/ACTION-PLAN.md](history/ACTION-PLAN.md) | План по понятности торговых решений и релевантности новостей |
| [history/SECUPD.md](history/SECUPD.md) | Трекер доработок по аудиту безопасности/надёжности |
| [history/trdupd.md](history/trdupd.md) | План правок Qwen3/Vulkan/KV |
| [history/PLAN-10-10-LIVE-PROFIT.md](history/PLAN-10-10-LIVE-PROFIT.md) | План доведения до Live; задачи в документе не выполнены |
| [history/PLAN-ML-LLM-INTEGRATION.md](history/PLAN-ML-LLM-INTEGRATION.md) | План ML/LLM-интеграции; задачи в документе не выполнены |
| [history/LOGGING-PLAN.md](history/LOGGING-PLAN.md) | Аудит логов и завершённый план реформы логирования |

`plann.md` из исходного архива был точной копией `plan.md` и не включён в подготовленную структуру.
