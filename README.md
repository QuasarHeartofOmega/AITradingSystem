# AITradingSystem

Экспериментальный торговый помощник на **.NET 8 / WPF** для Windows x64: Binance Spot / Demo, технические индикаторы, локальная GGUF-модель через LLamaSharp, риск-сайзинг, новости, биржевая защита OCO, реконсиляция и Telegram-уведомления.

> Проект не является финансовой рекомендацией и не гарантирует доходность. Перед любыми реальными ордерами проверяйте окружение, ключи, лимиты и режим торговли.

## Что это и как работает

Текущая архитектура — последовательный конвейер:

```text
Binance REST/WS → свечи/стакан → индикаторы → PreScore движка
→ локальная LLM → Blend confidence → риск/сайзинг/ликвидность
→ ExecutionQueue → post-only или market entry → OCO SL/TP
→ PositionMonitor / user-data stream / reconciliation → история сделок
```

Ключевые модули:

- `AITradingSystem.Services/Trading/TradingEngine.cs` — основной цикл, гейты, вход, пересмотр позиции.
- `AITradingSystem.Services/Analysis/SignalCalibrator.cs` — детерминированный `PreScore` и смешивание уверенности модели с prior движка.
- `AITradingSystem.Services/AI/QwenModel.cs` — локальный GGUF-инференс, retry/repair JSON, детектор дегенерата, KV-reuse.
- `AITradingSystem.Services/Trading/OrderExecutor.cs` — `LIMIT_MAKER` / market, ожидание филла, OCO, отмена остатка.
- `AITradingSystem.Services/Trading/PositionMonitor.cs` — независимый контур SL/TP/trailing.
- `AITradingSystem.Services/Trading/ReconciliationService.cs` — user-data stream, инвентаризация ордеров/позиций.
- `AITradingSystem.Core/RiskManagement/` — просадка, дневной лимит, портфельный риск, сайзинг, комиссии.

**Важно:** в текущем коде LLM всё ещё находится в критическом пути входа и может предлагать BUY/CLOSE. Целевой план — вынести её в `VetoOnly` / explainer, но это ещё не реализовано.

## Важное о режимах торговли

В предоставленной конфигурации:

```json
"Binance": { "Environment": "Demo" },
"Trading": { "PaperTradingMode": false, "UseMarketEntry": false, "AllowShort": false }
```

Это означает **отправку реальных ордеров в Demo-окружение Binance**, а не бумажную симуляцию.

- **Demo / Testnet** — виртуальные средства соответствующего окружения, нужны его ключи.
- **Live** — реальные средства. Не переключайтесь без явного намерения торговать на реальные деньги.
- **Paper** — движок симулирует ордера; сервис аккаунта при этом может читать настроенное биржевое окружение.
- `UseMarketEntry=false` — вход через post-only `LIMIT_MAKER`; это не гарантия исполнения.
- `AllowShort=false` — SELL без открытой позиции трактуется как невозможный спотовый шорт.
- Чтение балансов и ордеров начинается независимо от кнопки запуска торговли и не отправляет ордера.
- Настройки сохраняются рядом с exe. После изменения списка пар, окружения, режима, ключей или GPU-бэкенда перезапустите приложение.

### Список символов

`Trading:Symbols=[]` в `appsettings.json` **не означает пустой список**, если рядом есть `symbols.json` с непустым реестром. В предоставленном репозитории `symbols.json` задаёт 12 пар, включая `USDCUSDT` и `FDUSDUSDT`. В runtime-логе активными оказались 11 пар; `FLRUSDT` не попал в активные стримы и AI-анализ.

## Быстрый старт

Требования:

- Windows x64;
- .NET 8 SDK;
- Visual Studio 2022 17.8+ с нагрузкой «Разработка классических приложений .NET» — необязательно, можно собирать через `dotnet`.

```powershell
dotnet restore AITradingSystem.sln
dotnet build AITradingSystem.sln --configuration Release
dotnet test AITradingSystem.Tests/AITradingSystem.Tests.csproj --configuration Release
dotnet run --project AITradingSystem.UI/AITradingSystem.UI.csproj --configuration Release
```

По умолчанию подключаются CPU + CUDA12 + Vulkan нативные бэкенды LLamaSharp. Для первой сборки без GPU-пакетов:

```powershell
dotnet build AITradingSystem.sln --configuration Release -p:LlamaGpuBackends=none
```

Подробная настройка: [docs/SETUP-WINDOWS.md](docs/SETUP-WINDOWS.md).

## Конфигурация

- `AITradingSystem.UI/appsettings.json` — риск, окружение, AI, новости, Telegram, логирование.
- `AITradingSystem.UI/symbols.json` — реестр торговых пар, лимиты позиций, отслеживаемые активы и котировки.
- Оба файла копируются в output. Личные значения лучше менять в копии рядом с exe, а не в исходном шаблоне.
- Модель и native-библиотеки не включены в репозиторий. На целевой машине настройте `AI:ModelPath` и раскладку библиотек LLamaSharp.
- Ключи шифруются на целевой машине Windows через `SecretEncryptor`. Не добавляйте открытые ключи, личные конфигурации, логи и модели в Git.

## Что означает этот baseline

Подтверждено runtime-логом:

- запуск Demo-окружения и рыночного WS;
- загрузка модели и частичный GPU-оффлоад;
- `PreScore`, калибровка, финальные `ИТОГ`;
- блокировка входов по `confidence`, `risk`, `kill-switch`, `market-data`;
- отсутствие ордеров и закрытых сделок в наблюдаемом окне.

Не подтверждено:

- отправка и исполнение post-only входа;
- постановка и срабатывание OCO SL/TP;
- независимое аварийное закрытие;
- идемпотентность при повторной отправке;
- персист просадки и корректность equity/free-cash;
- реконсиляция и user-data stream;
- поведение при 429/-1003;
- fill probability, slippage, adverse selection;
- статистическое преимущество стратегии.

Подробный план исправлений: [PLAN-PROFIT-ENGINE.md](docs/history/PLAN-PROFIT-ENGINE.md).
